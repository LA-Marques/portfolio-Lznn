Motor Analítico de Dados Estatísticos dos Municípios do Paraná

Sistema construído em Python projetado para ingestão, filtragem e agregação estatística de indicadores socioeconômicos dos 399 municípios paranaenses (com ênfase em polos como Londrina, Curitiba, Maringá, Foz do Iguaçu e Jandaia do Sul).

Utiliza estruturas indexadas baseadas em tabelas hash (dicionários) para mapeamento de dados em tempo de acesso O(1), permitindo cruzamento relacional entre população, densidade demográfica e indicadores municipais com custo computacional mínimo.
