PROJETO PRINCIPAL // PYTHON & ESTRUTURAS IBGE / PR

Motor de Processamento Estatístico dos Municípios do Paraná

Sistema desenvolvido em Python projetado para ingestão, indexação e agregação estatística de indicadores socioeconômicos dos 399 municípios do Paraná.

Estruturado com tabelas hash (dicionários nativos), garantindo tempo de acesso e cruzamento analítico em complexidade O(1) sem o overhead de varreduras lineares em grandes massas de dados.
